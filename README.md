# ScreenShotRecorder

一款 Windows 桌面截图/录屏工具：全局快捷键一键唤起，支持区域截图与标注编辑、滚动长截图、区域录屏（MP4/GIF、系统声音/麦克风）、截图贴图。双进程架构，托盘常驻，随开随用。

## 功能特性

- **区域截图**：`F1` 全局唤起，框选任意区域，选区可微调
- **标注编辑**：矩形、椭圆、箭头、画笔、文字、马赛克/模糊（强度可调），12 色可选，粗细三档，支持撤销/恢复
- **滚动长截图**：框选区域后自动/手动滚动拼接长图
- **截图贴图**：将截图固定在屏幕最前端，随时对照参考
- **区域录屏**：可选录制系统声音/麦克风/混合，输出 MP4 或 GIF；录屏结束在录制区域中央弹出提示，一键打开保存目录
- **安装即用**：安装器自动部署全部运行库（含 VC++ 运行库静默安装），可选开机自启

## 环境要求

- Windows 10 / 11（64 位）
- 无需预装任何运行库，安装器已内置全部依赖

## 安装与卸载

### 安装

1. 从发布页下载 `ScreenShotRecorder_v<版本>_setup_x64.exe`
2. 双击运行安装向导（中文界面）
3. 选择安装路径（默认 `C:\Program Files\ScreenShotRecorder`，可自行更改）
4. 按需勾选「创建桌面快捷方式」「开机自动启动」（自启默认勾选，保证 `F1` 随时可用）
5. 完成安装后托盘区出现程序图标，按 `F1` 即可开始截图

> 首次运行提示：程序未做代码签名，浏览器下载或首次运行时可能弹出 SmartScreen/安全提示，
> 选择「保留」「仍要运行」即可。

### 卸载

- 通过「设置 → 应用」或开始菜单中的「卸载 ScreenShotRecorder」执行
- 卸载时会询问是否同时删除用户配置与日志，选择「否」可保留设置，重装后自动沿用

## 使用方法

安装后程序以托盘图标形式常驻（截图功能由托盘进程提供全局快捷键支持，请保持托盘运行）。

### 区域截图与标注

1. 按 `F1`（全局快捷键，任何界面下可用），屏幕进入截图模式
2. 按住鼠标左键拖拽框选区域，松开完成选区
3. 选区边缘可拖动微调位置与大小
4. 在工具栏选择编辑工具进行标注：
   - **矩形 / 椭圆 / 箭头 / 画笔**：选工具后在截图上直接绘制；按住 `Shift` 可绘制正方形/正圆
   - **文字**：点击位置输入文字，可调字号与颜色
   - **马赛克 / 模糊**：涂抹隐藏敏感信息，可切换马赛克/模糊效果、调整强度、选择涂抹形状（矩形/圆形/画笔）
   - **颜色**：在颜色面板选择标注颜色（按功能分别记忆）
   - **粗细**：三档线宽（细/中/粗，按功能分别记忆）
   - **撤销 / 恢复**：回退或重做上一步编辑
5. 编辑完成：
   - 点击**保存**按钮另存为图片文件
   - 点击**复制**按钮复制到剪贴板，直接粘贴到聊天窗口/文档
   - 点击**贴图**按钮将截图钉在屏幕最前端，方便对照录入
   - 点击 ✓ 或双击选区完成并复制；按 `Esc` 取消本次截图

### 滚动长截图

1. `F1` 框选需要截取的窗口区域
2. 点击工具栏**滚动截图**按钮，进入滚动拼接模式
3. 选择自动或手动模式：
   - **自动**：程序自动发送滚动并持续拼接，内容拼接完成自动停止
   - **手动**：自行滚动页面（滚轮），程序按节奏采集拼接
4. 完成后保存长图

### 区域录屏

1. `F1` 框选录制区域
2. 点击工具栏**录屏**按钮，可选音频来源：
   - 不录声音 / 仅麦克风 / 仅系统声音 / 麦克风+系统声音
   - 需要录制键鼠演示时，可开启「显示按键」叠加层
3. 3-2-1 倒计时后开始录制，计时窗实时显示时长，可最小化隐藏
4. 点击计时窗**停止**按钮结束录制
5. 录制结束后在录制区域中央弹出提示气泡：
   - 显示「录屏结束」与文件名；点击**打开目录**直接在资源管理器中定位录屏文件
   - 气泡 6 秒后自动消失（也可手动关闭）
6. 输出格式：MP4（默认）/ GIF（在录屏选项中切换，自动转码）

> 若系统声音设备获取失败，程序会自动降级（如"系统声音"降级为不录音、"混合"降级为仅麦克风）并在日志中记录。

## 数据存储位置

用户配置与日志保存在用户数据目录（不随卸载删除，除非卸载时确认删除）：

```
%LOCALAPPDATA%\ScreenShotRecorder\
├── config\settings.ini     # 颜色/粗细等偏好（按功能记忆）
└── logs\                   # 运行日志（按日轮转，排查问题用）
```

## 常见问题

**Q：按 F1 没有反应？**
确认托盘区有程序图标（托盘进程负责全局快捷键）；未运行时从开始菜单启动 ScreenShotRecorder。

**Q：浏览器/系统提示程序有风险？**
程序暂未做代码签名，属正常提示，选择「保留」「仍要运行」；建议从本仓库 Release 页下载以获得原始安装包。

**Q：录屏没有声音？**
检查录制前的音频来源选择是否匹配需求；若系统默认播放/录音设备被禁用，程序会自动降级录音方案，详见日志。

**Q：重装后设置会丢吗？**
不会。配置保存在用户数据目录，卸载时选择保留即可；仅当卸载时确认删除后才会清空。
